# Phase 2.5 Plan 02: B2B Colour Token Update Summary

**One-liner:** Shift CSS design tokens from warm mid-blue (201 70% 42%) to a deeper authority blue (213 62% 36%) with cooler neutrals — globally upgrading all pages to B2B-grade healthcare aesthetic without any component edits.

---

## What Was Built

### Token Changes Applied

All changes are in `client/src/index.css` `:root` block — HSL value updates only. No class names,
property names, structural rules, or comments outside `:root` were touched.

| Token | Before | After | Intent |
|-------|--------|-------|--------|
| `--background` | `0 0% 97%` | `210 20% 98%` | Slightly cooler off-white — less warm, more clinical |
| `--foreground` | `220 15% 20%` | `220 20% 16%` | Deeper slate — stronger contrast ratio |
| `--card-foreground` | `220 15% 20%` | `220 20% 16%` | Aligned with foreground |
| `--popover-foreground` | `220 15% 20%` | `220 20% 16%` | Aligned with foreground |
| `--primary` | `201 70% 42%` | `213 62% 36%` | Deeper authority blue — B2B trust (#1254a4 range) |
| `--ring` | `201 70% 42%` | `213 62% 36%` | Matched to new primary |
| `--secondary` | `210 20% 93%` | `215 25% 91%` | Cooler, slightly more contrast |
| `--secondary-foreground` | `220 15% 35%` | `220 20% 32%` | Deeper for legibility |
| `--muted` | `210 20% 95%` | `215 20% 94%` | Cooler neutral family |
| `--muted-foreground` | `220 10% 50%` | `220 12% 46%` | Deeper for accessibility |
| `--accent` | `210 20% 93%` | `215 25% 91%` | Aligned with secondary |
| `--accent-foreground` | `220 15% 25%` | `220 20% 22%` | Deeper for contrast |
| `--border` | `210 20% 88%` | `215 20% 86%` | Cooler, crisper B2B edge |
| `--input` | `210 20% 88%` | `215 20% 86%` | Aligned with border |
| `--card` | `0 0% 100%` | `0 0% 100%` | Unchanged — pure white cards |
| `--primary-foreground` | `0 0% 100%` | `0 0% 100%` | Unchanged |
| `--destructive` | `0 65% 48%` | `0 65% 48%` | Unchanged — status colour |
| `--radius` | `0.75rem` | `0.75rem` | Unchanged |

### Propagation

The token system is wired via `hsl(var(--primary))` references in `tailwind.config.js`. Every
component using `bg-primary`, `text-muted-foreground`, `bg-background`, `border-border`, etc.
automatically inherits the new palette. No component-level edits were needed.
