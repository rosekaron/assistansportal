# Phase 2.5 Plan 05: Remaining Pages Consistency Pass Summary

**One-liner:** Eliminated all remaining dark-mode colour artefacts across Leave, Login, Calendar, Reports, Assistants, and Settings — completing the Phase 2.5 design system rollout with consistent primary tokens, light badges, and B2B-grade typography.

---

## What Was Built

### Task 1 — Leave.tsx and Login.tsx

All changes are JSX/className only. Data fetching, mutations, form state, and business logic are unchanged.

**Leave.tsx:**

| Area | Before | After | Reason |
|------|--------|-------|--------|
| Balance card value | `text-3xl font-semibold` | `text-2xl font-bold` | Matches Dashboard card hierarchy from Plan 03 |
| Balance card label | `text-sm text-muted-foreground` | `text-xs font-medium text-muted-foreground uppercase tracking-wide` | Section label pattern — consistent |
| CardContent padding | `CardContent` (default) | `CardContent className="pt-0"` | Title already has pb-2; avoid double-gap |
| Fill bar track | `h-1 bg-secondary` | `h-1.5 bg-muted` | Taller bar; muted is correct token |
| Table row border | `border-border/50` (semi-transparent) | `border-border` (solid) | Sharper row separators |
| Table row padding | `py-2` | `py-3` | Comfortable density per plan spec |

**Login.tsx:**

| Area | Before | After | Reason |
|------|--------|-------|--------|
| Page background | `style={{ background: "linear-gradient(135deg, …)" }}` inline | `bg-muted/30` | Token-based, consistent with all other pages |
| Logo bg | `style={{ background: "hsl(201 70% 42%)" }}` inline | `bg-primary` | Design system token, not hardcoded hsl |
| Card shadow | No explicit shadow | `shadow-lg` | B2B first-impression depth |
