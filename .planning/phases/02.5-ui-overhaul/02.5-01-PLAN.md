<objective>
Fix the Tailwind CSS build so that utility classes are generated and rendered in the browser.

Purpose: The app is currently unstyled — only 51 base CSS rules are generated because Tailwind's JIT
silently fails to load `tailwind.config.js`. The root cause is a CJS `require()` call inside an ESM
module context. This plan eliminates that root cause by converting the config to a valid ES module.
All visual work in Plans 02–05 depends on this fix being in place first.

Output: `client/tailwind.config.js` converted to full ESM syntax. Dev server renders utility classes.
</objective>
