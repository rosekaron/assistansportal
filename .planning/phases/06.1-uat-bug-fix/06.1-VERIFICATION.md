**Expected:** Within a few minutes, the recipient inbox receives an email from the configured GMAIL_USER with:

- Body includes a personal message if provided

**Credentials note:** Test login credentials are required to trigger the invite flow. See project memory for test credentials, or use the guardian account set up during Phase 6 UAT.
