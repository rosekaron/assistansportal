**Numeric formatting helpers (define before the component):**

```typescript
/** Format SEK amount using sv-SE locale. Output: "15 234 kr" or "15 234,50 kr" */
function formatSek(amount: number): string {
  const formatted = new Intl.NumberFormat("sv-SE", {
    minimumFractionDigits: Number.isInteger(amount) ? 0 : 2,
    maximumFractionDigits: 2,
  }).format(amount);
  return `${formatted} kr`;
}

/** Format hours: integer or one decimal, no space before "h". E.g. "87h" or "87,5h" */
function formatHours(hours: number): string {
  const val = Number.isInteger(hours) ? hours : parseFloat(hours.toFixed(1));
  return `${String(val).replace(".", ",")}h`;
}

/** Parse absenceBreakdownJson into a display string.
 *  Input: '{"sjukfrånvaro":8,"vab":0,"semester":16,"other":0}'
 *  Output: "sjukfrånvaro 8h, semester 16h" (omit types with 0 hours; "0h" if all zero)
 */
function formatAbsenceBreakdown(json: string | null): string {
  if (!json) return "0h";
  try {
    const breakdown = JSON.parse(json) as Record<string, number>;
    const parts = Object.entries(breakdown)
      .filter(([, h]) => h > 0)
      .map(([type, h]) => `${type} ${formatHours(h)}`);
    return parts.length > 0 ? parts.join(", ") : "0h";
  } catch {
    return "0h";
  }
}

/** YYYY-MM month helpers */
function monthLabel(month: string): string {
  const [year, mon] = month.split("-");
  const d = new Date(parseInt(year), parseInt(mon) - 1, 1);
  return d.toLocaleDateString("sv-SE", { month: "long", year: "numeric" });
}

function prevMonth(month: string): string {
  const [year, mon] = month.split("-");
  const d = new Date(parseInt(year), parseInt(mon) - 2, 1);
  return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, "0")}`;
}

function nextMonth(month: string): string {
  const [year, mon] = month.split("-");
  const d = new Date(parseInt(year), parseInt(mon), 1);
  return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, "0")}`;
}

function currentMonth(): string {
  const d = new Date();
  return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, "0")}`;
}
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /api/payroll (generate) | Month string from client drives server-side DB query; validated server-side (Plan 03 handles) |
| browser → /api/payroll/:id/approve | Approve mutation sent by client; server guards against re-approval with 409 (Plan 03 handles) |
| browser → /api/payments (POST) | Amount from client number input; server validates positive number via Zod (Plan 03 handles) |
| browser → /api/payments/:id (DELETE) | Delete sent by client; server verifies payment existence before removal (Plan 03 handles) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-10 | Tampering | Payroll.tsx — amount input sent to POST /api/payments | mitigate | Client uses `parseFloat` on user input; server-side Zod validates `amountSek: z.number().positive()` (Plan 03 Task 2); client cannot bypass server validation |
| T-03-11 | Tampering | Payroll.tsx — delete payment button without confirmation | mitigate | `window.confirm()` required before `deletePaymentMutation.mutate()` per UI-SPEC accessibility contract; user must explicitly confirm destructive action |
| T-03-12 | Information Disclosure | Payroll.tsx renders all assistants' payroll data for the authenticated guardian | accept | Single-tenant deployment (D-03); guardian is the only user who can access /payroll; requireGuardian enforced server-side |
| T-03-13 | Spoofing | payrollApi / paymentsApi axios calls include Authorization header | accept | Existing `api.interceptors.request.use` in api.ts already attaches `Bearer {token}` to all requests; no client-side change needed |
| T-03-14 | Denial of Service | Double-click on "Generera löneunderlag" sending duplicate generate requests | mitigate | `generateMutation.isPending` disables the button while the request is in-flight; server also returns existing record idempotently (Plan 03 Task 1) |
