# Phase 7 — UI Design Contract

## Spacing Scale

All spacing flows through Tailwind's default 4px grid (`space-y-3` = 12px, `space-y-4` = 16px, `gap-3` = 12px). Declared tokens:

| Token | Tailwind class | Value | Usage in Phase 7 |
|-------|----------------|-------|------------------|
| xs | `space-y-1.5`, `gap-1.5` | 6px | Field label → input gap (matches `Settings.tsx:36`) |
| sm | `space-y-3`, `gap-3` | 12px | Between fields inside a section, side-by-side field row gap |
| md | `space-y-4`, `gap-4`, `px-4 py-4` | 16px | Card inner padding, section header → first field gap |
| lg | `mt-8`, `mb-3` pair | 32/12px | Between Settings sections on the page (matches `Settings.tsx:670`) |
| xl | `py-6` | 24px | Dialog content vertical breathing room |

**Exceptions:**
- Field label-to-input gap uses 6px (`space-y-1.5`), not the 8-point scale. Pre-existing project convention at `Settings.tsx:36`; Phase 7 matches existing patterns, does not reset them.
- Collapsible section header row: `py-3 px-4` (12/16), matching shadcn accordion conventions already used by `tailwindcss-animate`.

**Dialog width exception:** Existing assistants edit dialog is `max-w-md` (28rem). With 17 fields across 2 sections, raise to `max-w-lg` (32rem) so two-column grids (`grid-cols-2`) render without cramping on the bank-detail and employment-date rows.

## Interaction Contract

### Collapsible section behavior (D-10, D-11)

1. First open of a dialog: Section 1 (Personuppgifter) is expanded, Section 2 (Anställning & ekonomi / FK-beslut) is collapsed.
2. Clicking a section header toggles its open state. State is local to the dialog instance — not persisted across sessions.
3. Chevron rotates via Tailwind `transition-transform` + `rotate-90` when open (matches `tailwindcss-animate` accordion convention already in the config).
4. Keyboard: header is `<button>`, `Enter` / `Space` toggles, `Tab` moves to first field of expanded section, `Shift+Tab` wraps to previous section's last field.
5. An expanded section's content uses `animate-accordion-down`; a collapsed section uses `animate-accordion-up` (both pre-declared in `tailwind.config.js:46`).
6. When a section is collapsed, its inputs are hidden from the tab order (`display: none`), not visually hidden — this matches native form semantics and avoids accidental keyboard traversal through collapsed content.
7. Saving is global to the dialog: one `Spara ändringar` button at the dialog footer submits all fields across both sections regardless of open/closed state. Guardian never has to "open all sections" to save.

### Dialog width raise (existing `max-w-md` → `max-w-lg` for assistants dialog)

- Justification: 17 fields incl. five `grid-cols-2` paired rows — `max-w-md` (28rem) would force single-column layout and double dialog height.
- Profile section is page-embedded (not a dialog), so width is governed by the existing Card container at `Settings.tsx:704`.

### Scheduling card removal (CLEAN-01)

- The entire `<SectionLabel>Scheduling</SectionLabel>` block and its container `<Card>` at `Settings.tsx:619` are deleted in a single atomic commit (D-13).
- No "deprecated" banner, no transition period, no feature flag — the card is dead code per ROADMAP verification.
- Page vertical rhythm self-heals: Integrations card flows directly into Payroll rates card with the standard `mt-8` gap.

### Validation surfacing (D-18)

- Client-side: HTML5 `pattern`, `min`, `max`, `type="date"`, `type="email"` attributes only. Browser-native bubbles appear on submit-blocked fields.
- Server-side rejection of whitelist-missed fields returns 400; client displays generic error below primary CTA (see Error state copy above).
- No custom inline field-level validation UI in Phase 7. Strict validators (IBAN checksum, pno control digit, skattetabell range inclusivity) are deferred to v1.2 per D-18.

## Accessibility

- Every new `<Input>` has an associated `<Label>` via the existing `SettingsField` pattern; `htmlFor` / `id` wiring is inherited from the primitive.
- Collapsible section header is a `<button type="button">` (not `<div onClick>`), with `aria-expanded`, `aria-controls` pointing to the section content region `id`.
- Focus-visible outline is 2px solid `hsl(var(--ring))` with 2px offset (already in `index.css:73`).
- All new Swedish labels are language-tagged via the existing `<html lang="sv">` root attribute — no per-field `lang` override needed.
- Color contrast: all new copy uses `text-foreground` (16% slate on 98% off-white ≈ 12:1) or `text-muted-foreground` (46% slate ≈ 4.7:1). Both exceed WCAG AA 4.5:1 for body text.
- Touch targets: dialog fields render at 40px minimum height via `Input` primitive default; section-header buttons at 44px (`py-3` = 12px + 20px text + 12px = 44px). No 44px exception for Phase 7.
