**State:**
- `[markAbsentEntry, setMarkAbsentEntry]` — the { assistantId, assistantName, date } being marked, or null
- `[absenceType, setAbsenceType]` — selected absence type string (default "sjukfrånvaro")

**Data queries (same pattern as Dashboard.tsx):**
- profile query
- assistants query
- entries query for all entries
- payroll query for invoiceMonthStr (use same FK deadline derivation from Dashboard.tsx lines 56-76)
- fkDownload mutation (pdfApi.fk3057)
- markAbsent mutation (absenceApi.create)

**Computed values:**
- weekDates = getWeekDates(0) — no navigation, always current week
- gcalConnected = !!profile?.gcalCalendarId
- pendingApprovals = entries filtered to reqStatus==="approved" && repStatus==="pending"
- payrollPendingCount = payrollRecords.filter(r => r.status === "draft").length
- byDay: same as Dashboard.tsx byDay computation
- invoiceHours, invoicePending (from Dashboard.tsx FK logic)

**Layout (top to bottom per UI-SPEC):**

1. PageHeader: greeting() + today's date + profile?.patientName

2. GCal status banner (conditional):
   - Not connected: blue info banner "Connect Google Calendar in Settings →" with link
   - Connected: small emerald "Synced with Google Calendar ✓" note (subtle, not a banner)

3. **This week's schedule** section (Card):
   - Section heading "This week's schedule"
   - 7-column grid (grid-cols-7 gap-1) — one column per day Mon–Sun
   - Each cell: day name (Mon/Tue/...), date number, assistant avatars + names, hours
   - If no entries for a day: cell is dimmed (opacity-40)
   - "Mark absent" button shown per day when gcalConnected and the day has entries
     - On click: setMarkAbsentEntry({ assistantId, assistantName, date })
   - On mobile (sm breakpoint): grid-cols-3 or scroll; keep desktop grid-cols-7

4. **Pending actions** section:
   - If pendingApprovals.length === 0 AND payrollPendingCount === 0:
     Show "All caught up — nothing pending" with CheckCircle2 icon
   - Otherwise: show amber action cards (same style as Dashboard Needs Attention):
     - Reports pending card: "{pendingApprovals.length} reports to approve" → onClick navigate("/monthly")
     - Payroll pending card: "{payrollPendingCount} payroll records to approve" → onClick navigate("/monthly") (only when payrollPendingCount > 0)
     - FK deadline: days until due (same as Dashboard)
     - FK download button: onClick fkDownload.mutate(); disabled when invoicePending > 0 OR invoiceHours === 0; title="Approve all reports and payroll first" when disabled

5. **Setup banner** (conditional): copy the exact setupDone logic from Dashboard.tsx — show
   the existing setup progress card when !profile?.setupDone

6. **Mark absent dialog** (conditional — shown when markAbsentEntry !== null):
   - Use Dialog component from ui/ if available, otherwise a fixed overlay div
   - Title: "Mark {markAbsentEntry.assistantName} as absent?"
   - Absence type selector (4 options):
     - "Sick leave" → value "sjukfrånvaro"
     - "VAB" → value "vab"
     - "Holiday" → value "semester"
     - "Other" → value "other"
   - Date shown (the shift date from markAbsentEntry.date)
   - Buttons: "Confirm" (calls markAbsent.mutate) + "Cancel" (clears state)
   - On success: invalidate entries and absence queries; close dialog

Keep the same Card/Button/Badge component patterns as Dashboard.tsx. Reuse the exact same
FK deadline calculation lines from Dashboard.tsx (copy the 20-line block, do not reimplement).
