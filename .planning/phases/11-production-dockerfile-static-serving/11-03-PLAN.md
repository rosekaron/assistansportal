- `DATABASE_URL` uses `host.docker.internal` (RESEARCH Pitfall 5) so the container can reach the host's Postgres (running via the existing docker-compose).

- `FK_HOURLY_RATE` and `EMPLOYER_TAX_RATE` use the Three Binding Guardian Directions values from ROADMAP HANDOFF (254.10 kr/h; 31.42% employer tax).
