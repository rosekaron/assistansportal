# Phase 2.5 Plan 03: Guardian Layout & Dashboard Redesign Summary

**One-liner:** Redesigned Layout.tsx sidebar (logo size, nav hover tokens, brand-tinted weekly hours widget) and Dashboard.tsx (card title hierarchy, today-cell ring, taller fill bar, primary-token invoice hours) to B2B-professional standard.

---

## What Was Built

### Task 1 — Layout.tsx sidebar

All changes are JSX/className only. Imports, hooks, nav array, data fetching, and event handlers are unchanged.

| Area | Before | After | Reason |
|------|--------|-------|--------|
| Logo icon | `w-8 h-8` (32px) | `w-9 h-9` (36px) | Slightly more presence; still proportional |
| Logo area | No separator | `border-b border-border pb-5 mb-2` on inner div | Clear visual break between logo and nav |
| Product name | `font-semibold` | `font-bold` | Stronger product identity |
| Nav inactive hover | `hover:bg-secondary` | `hover:bg-muted` | Muted is lighter — subtler inactive hover |
| Nav active text | `text-white` | `text-primary-foreground` | Correct token usage (white is the value, but token is the contract) |
| Nav transition | `transition-all` | `transition-colors duration-150` | More targeted, faster |
| Weekly hours bg | `bg-blue-50` | `bg-primary/10` | Brand-tied, not hardcoded blue |
| Weekly hours border | None | `border border-primary/15` | Subtle definition for the widget |
| Weekly hours padding | `px-3 py-2.5` | `px-4 py-3` | Slightly more generous |
| Weekly hours label | `text-xs text-muted-foreground` | `+ uppercase tracking-wide font-medium` | Uppercase label increases visual weight |
| Weekly hours value | `text-lg font-bold` | `text-2xl font-bold` | Key status number — deserves prominence |

### Task 2 — Dashboard.tsx

All changes are JSX/className only. All data logic, React Query hooks, mutations, calculated values, and navigation handlers are unchanged.

| Area | Before | After | Reason |
|------|--------|-------|--------|
| Week coverage title | `text-sm font-semibold` | `text-base font-semibold` | Stronger card section hierarchy |
| Today day cell | `border-primary bg-primary/5` | `border-primary/40 bg-primary/8 ring-1 ring-primary/20` | More visible today indicator with ring |
| Non-today empty cell | `opacity-50` applied separately | Inlined into cn() ternary | Cleaner conditional logic |
| Non-today filled cell | `bg-secondary/30` | `bg-secondary/20 hover:bg-secondary/40 transition-colors` | Hover affordance on clickable context |
| Fill bar track | `h-2 bg-secondary` | `h-2.5 bg-muted` | Slightly taller for visibility; muted is correct |
| FK invoice hours | `text-blue-400` | `text-primary` | Remove hardcoded colour, use design token |
| Setup banner button | `rounded-lg` | `rounded-xl` | Border-radius consistency across UI |
| Assistant row hover | None | `hover:bg-muted/50 rounded-lg px-2 py-1.5 -mx-2 transition-colors` | Subtle hover affordance |
