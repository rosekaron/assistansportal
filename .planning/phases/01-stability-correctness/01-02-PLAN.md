<objective>
Wire role enforcement middleware to all guardian-facing routes and sanitize all catch blocks across every route file.

Purpose: The role middleware (`requireGuardian`, `requireAssistant`) already exists and is correct. The only gap is that routes currently use only `requireAuth`, which any authenticated user passes. - `auth.ts` catch blocks sanitized

- STAB-01 regression tests turn GREEN
