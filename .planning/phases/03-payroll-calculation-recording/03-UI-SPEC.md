## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding, row gaps within a stat group |
| sm | 8px | Gap between label and value in a stat cell, button internal gaps |
| md | 16px | Card internal padding (matches `p-5` = 20px on Card primitives — use `p-4` for tighter sections) |
| lg | 24px | Gap between assistant payroll cards, section separators |
| xl | 32px | Top-of-page gap between month selector row and cards list |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

**Standard card padding:** `p-5` (20px) — inherited from `CardHeader`/`CardContent` in `card.tsx`.

**Page outer padding:** `px-8 py-8` (32px) — inherited from `Layout.tsx` main content wrapper. Do not override.

**Month selector row bottom margin:** `mb-6` (24px) — matches `PageHeader` pattern in `shared.tsx`.

Exceptions:
- Payment history row height: `py-2.5` (10px vertical) — matches sidebar nav item height for visual rhythm.
- Add Payment form fields: `space-y-3` (12px) between label+input pairs — matches `Settings.tsx` form pattern.
- Stat grid cells: `gap-4` (16px) between columns — keeps numeric data scannable without crowding.

## Page Layout Contract

### Route: `/payroll` → `client/src/pages/Payroll.tsx`

**Outer structure:**
```
PageHeader title="Löneunderlag" description="Månatlig lönekalkyl per assistent"
  action={month selector}

[card per assistant — vertical stack, gap-6]
```

**Month selector (top-right of PageHeader action slot):**
- `<` ChevronLeft button (ghost, icon size) — previous month
- `MMMM YYYY` label — `text-sm font-semibold text-foreground min-w-[120px] text-center`
- `>` ChevronRight button (ghost, icon size) — next month
- Pattern mirrors `Reports.tsx` month navigation exactly (lines 149–157 of Reports.tsx)

**Assistant payroll card (collapsed — default state):**
```
CardHeader:
  left:  AssistantAvatar + assistant name (text-lg semibold) + status badge (draft | Godkänd)
  right: "Godkänn" Button (variant=default) OR "Godkänd ✓" Button (variant=approve, disabled)

CardContent:
  Stat grid — 5 columns, gap-4:
    [Fakturerbara timmar] [Frånvarotimmar] [Bruttolön] [Arbetsgivaravgift] [Total kostnad]
    value: text-xl font-semibold font-mono tabular-nums
    label: text-xs text-muted-foreground uppercase tracking-wide

  Absence breakdown (only if absence hours > 0):
    SectionLabel "Frånvaro per typ"
    Badge row: sjukfrånvaro Nh | VAB Nh | semester Nh | övrigt Nh  (variant=warning)

  Separator

  SectionLabel "Betalningar"
  Payment history list (or EmptyState "Inga betalningar registrerade ännu.")
  "Lägg till betalning" toggle button (ghost, small)

  [if expanded — Add Payment form]:
    date input, amount input (SEK), method select (Bankgiro | Swish | Kontant)
    "Spara betalning" Button (variant=default, sm) + "Avbryt" Button (variant=ghost, sm)

CardFooter:
  "Utestående saldo: X kr" — text-sm font-mono
    color: text-emerald-700 if 0, text-amber-700 if > 0
```

**Card expansion:** The payment history + Add Payment form section is always visible within the card (no accordion collapse required — D-11 says "inline within the card"). The "Lägg till betalning" toggle shows/hides only the Add Payment form row.

## Interaction States

| State | Trigger | Visual Treatment |
|-------|---------|-----------------|
| Loading (fetching payroll) | Page mount / month change | Skeleton cards — 2 placeholder cards at full card height, `animate-pulse bg-muted rounded-xl` |
| Empty (no payroll generated) | No `payroll_records` for month | `EmptyState` with "Generera löneunderlag" Button (variant=default) |
| Draft card | `payroll_records.status === "draft"` | `Badge variant="slate"` label "Utkast" + active Approve button |
| Approved card | `payroll_records.status === "approved"` | `Badge variant="success"` label "Godkänd" + disabled approve button (`variant="approve"`) |
| Add payment form open | User clicks "Lägg till betalning" | Form rows appear below separator with `animate-accordion-down` (keyframe already in tailwind.config.js) |
| Delete payment hover | Hover on payment row | Show trash icon button (`variant="ghost"` size="icon") with `text-destructive` |
| Approve mutation pending | POST `/api/payroll/:id/approve` in-flight | Approve button shows spinner (disabled + `opacity-50`) |
| Save payment pending | POST `/api/payments` in-flight | "Spara betalning" disabled + spinner |

## Numeric Formatting Rules

These rules apply to all currency and hour values on this page. They are load-bearing for compliance review.

| Value type | Format | Example |
|-----------|--------|---------|
| SEK currency | `{amount} kr` — no decimal if whole number, 2 decimal places if fractional — space before `kr` | `15 234 kr` or `15 234,50 kr` |
| Hours | `{N}h` — integer or one decimal — no space before `h` | `87h` or `87,5h` |
| Percentage (employer contribution rate) | `{rate}%` — shown in stat cell label as `(31,42%)` | `(31,42%)` |
| Swedish decimal separator | Comma `,` — not period — matches Swedish locale standard | `15 234,50` not `15,234.50` |
| Swedish thousands separator | Non-breaking space — matches Swedish locale standard | `15 234` not `15,234` |

**Implementation note:** Use `new Intl.NumberFormat('sv-SE', { style: 'currency', currency: 'SEK' })` or format manually — do not use `toLocaleString()` without explicit locale. Incorrect separators will fail a compliance review.

## Accessibility Contract

| Requirement | Implementation |
|------------|----------------|
| Approve button minimum touch target | 36px height (`h-9`) — already the default button size |
| Keyboard navigation | All interactive elements reachable by Tab; Approve → Add payment → form fields → Save → Cancel |
| Focus ring | `focus-visible:ring-2 focus-visible:ring-ring` — already on Button primitive; do not suppress |
| Approved card — screen reader | Disabled Approve button must have `aria-label="Löneunderlag godkänt"` (disabled buttons lose accessible name) |
| Delete confirmation | Use `window.confirm()` for Phase 3 (no Dialog component needed); escalate to Dialog only if UX review flags it |
| Currency screen reader | Render SEK amounts as `<span aria-label="{N} kronor">{N} kr</span>` for amounts in stat cells |
| Loading skeletons | Wrap in `role="status" aria-label="Laddar löneunderlag..."` |
