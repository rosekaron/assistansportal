## What Was Built

Four endpoints in `server/src/routes/guardian-links.ts`:

| Endpoint | Role | Behavior |
|----------|------|----------|
| `GET /api/guardian-links` | guardian | Returns all links for the JWT guardian, joined with assistant name/email |
| `POST /api/guardian-links` | guardian | Creates an inactive link; 400 if no assistantId; 404 if assistant missing; 409 on duplicate |
| `GET /api/guardian-links/my-families` | assistant | Returns active links for the JWT-resolved assistant |
| `POST /api/guardian-links/:id/accept` | assistant | Activates a link; 404 if not found or wrong assistant; 409 if already active |

Registered at `/api/guardian-links` in `server/src/index.ts`.
